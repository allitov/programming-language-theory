Напиши программу, реализующую функционал ДМП-автомата.
Вход: Функция переходов автомата и цепочки символов для проверки (текстовый файл .txt) (цепочки запрашиваются в консоли)
Выход: Вывод о принадлежности цепочки заданному языку (в консоль). Если цепочка не была принята, программа должна
вывести причину.
Каждый шаг автомата нужно выводить в консоль.
Все сообщения в консоль выводятся на английском языке.

Соглашения по наименованию:

- состояния автомата именуются в формате `q0, q1 ... q5`;
- `Z` - начальный (нулевой) символ магазина. Он всегда есть в начале работы автомата.
- формат, отображающий состояние автомата: `(q1, abc, aZ)`, где `q1` - текущее состояние автомата, `abc` - текущая еще
  не обработанная цепочка, `aZ` - текущее содержимое магазина (на вершине стека находится `a`);
- пустая цепочка или пустой магазин обозначаются `λ` (юникод `U+03BB`);

Формат вывода шагов работы автомата:

```
1) (q0, abc, Z) -> (q1, bc, aZ)
2) (q1, bc, aZ) -> (q2, c, Z)
3) (q2, c, Z) -> (qf, λ, λ)
```

Формат входных данных:

- states - возможные состояния автомата;
- alphabet - доступный алфавит цепочек;
- stack - возможные символы в магазине;
- start - начальное состояние автомата;
- final - конечные состояния автомата;
- transitions - переходы автомата;

Что можно делать со стеком (показана только вершина стека!):

1) Добавить символ: `Z` -> `aZ`;
2) Удалить символ: `a` -> `λ`;
3) Ничего не делать со стеком: `a` -> `a`;

Пример:

```
states: q1 q2 q3 q4 q5 q6
alphabet: 0 1
stack: Z 0 1
start: q4
final: q1 q5

transitions:
q4 0 Z = q5 0Z
q5 1 0 = q5 λ
...
```
